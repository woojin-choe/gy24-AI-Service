# 신청 서식 조사와 PDF 개선

확인일: 2026-10-05

## 사용자가 선택한 공고

[서울] 2026년 외국인 취업채용박람회 참가기업 모집 공고

- 기업마당: https://www.bizinfo.go.kr/sii/siia/selectSIIA200Detail.do?pblancId=PBLN_000000000126951
- 공식 원문: https://www.mss.go.kr/site/seoul/ex/bbs/View.do?bcIdx=1071297&cbIdx=146
- 공식 모집자료: https://www.mss.go.kr/common/board/Download.do?bcIdx=1071297&cbIdx=146&streFileNm=5f4303ed-a42a-4576-a856-233fefc72ec1.pdf
- 온라인 참가신청: https://2026seouljobfair.com/apply?type=company

공식 모집자료는 참가신청서, 사업자등록증, 그 외 기타 서류(해당 시) 각 1부를 안내합니다. 외국인 채용경험 우대는 입증서류가 필요합니다. 서울 소재 사업장 여부와 외국인 채용 희망 여부도 확인해야 합니다.

확인한 첨부 PDF는 1페이지 모집안내이며, 입력칸이 있는 참가신청서 서식이 아닙니다. 온라인 신청 페이지가 존재하지만 초기 화면만으로 전체 입력 항목을 확정하지 못했습니다. 자유양식 PDF 업로드를 허용하는지는 확인되지 않았습니다.

## 다른 고용지원사업의 양식

- 청년일자리도약장려금은 별도의 참여신청 및 사업운영 지침이 있습니다. 고용24 공식 안내: https://www.work24.go.kr/cm/c/f/1100/selecSystInfo.do?systClId=SC00000117&systCnntId=CI00001044&systId=SI00000318
- 2026 고용장려금 지원제도 안내: https://moel.go.kr/news/notice/noticeView.do?bbs_seq=20260200770

신청서 양식은 사업별로 달라 공통 질문 3개와 자유양식 PDF만으로 공식 신청을 대체할 수 없습니다. 이번 개선은 검토용 준비서 디자인과 확인된 공고별 준비사항을 반영합니다.

## 이번 개선

- 브랜드 헤더와 공고명 강조 영역
- 회사 기본정보 표
- 신청 내용 카드와 보완 필요 표시
- 공고 개요, 실제 링크, 첨부자료 / 본문 자료 링크
- 조사 완료 공고의 요구사항과 공식 출처 표시
- 대표자 확인 및 서명 영역, 페이지 번호
- 내용 길이에 따른 페이지 분할과 서명 영역 유지

실제 제출용 자동 완성은 공식 입력 항목 또는 양식 파일을 확인한 뒤 사업별 매핑을 구현해야 합니다. 이 기능은 아직 완료되지 않았습니다.
