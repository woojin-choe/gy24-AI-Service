# 이음 구현 현황 및 팀원 사용법

작성일: 2026-10-05

## 목표와 현재 상태

이음은 사업장 정보를 한 번 등록하면 관련 고용지원 공고를 발견하고, 부족한 정보만 대화로 받아 신청 자료를 준비하는 AI 비서를 목표로 합니다.

현재는 로컬에서 실행되는 프로토타입입니다. **기업마당 실제 공고 조회는 연결되어 있고, LLM은 키를 설정해야 사용됩니다.** 공고 자동 선정, 신청서 초안의 사전 작성 및 공식 양식 자동 완성은 아직 구현되지 않았습니다.

## 지금까지 구현한 기능

## 처음 실행하는 팀원

### 1. 저장소 받기

처음이면 아래 명령을 실행합니다.

```bash
git clone https://github.com/woojin-choe/gy24-AI-Service.git
cd gy24-AI-Service
```

이미 받은 저장소라면 커밋하지 않은 작업이 없는지 확인하고 `git pull`로 업데이트합니다.

### 2. 앱 폴더에서 설치 및 설정

Node.js 22.13 이상을 설치한 뒤 저장소 루트에서 실행합니다.

```bash
cd contests/employment24/ieum-app
npm ci
cp .env.example .env
```

팀 공용 기업마당 인증키가 `.env.example`에 포함되어 있습니다. 위 복사 명령을 실행하면 바로 실제 공고를 조회할 수 있습니다. 다른 키를 사용하려면 `.env`의 `BIZINFO_API_KEY`를 변경합니다. 키 없이도 체험용 공고로 사용할 수 있습니다.

```env
BIZINFO_API_KEY=복사된_팀공용_인증키
LLM_API_URL=
LLM_API_KEY=
LLM_MODEL=
PDF_FONT_PATH=/System/Library/Fonts/Supplemental/Arial Unicode.ttf
```

실제 `.env` 파일과 저장한 회사 정보는 Git에서 제외되어 있습니다. 사용자 요청에 따라 기업마당 팀 공용 키만 `.env.example`로 공유합니다. 개인 LLM 키는 이 파일에 추가하지 않습니다.

### 3. 한글 PDF 글꼴 확인

macOS 기본 글꼴 경로를 사용합니다. Windows·Linux 또는 해당 글꼴이 없는 환경에서는 한글을 지원하는 TTF 파일을 준비해 `PDF_FONT_PATH`를 실제 경로로 수정합니다. 글꼴이 없으면 사이트는 열리지만 PDF 생성은 실패합니다. 시스템 글꼴은 저장소에 포함하지 않았습니다.

### 4. 실행

```bash
npm run dev
```

브라우저에서 http://localhost:3001 을 엽니다. 터미널은 실행 상태로 두고, 종료할 때는 `Ctrl+C`를 누릅니다. 포트가 사용 중이면 `npm run dev -- --port 3002`를 실행하고 터미널에 표시된 주소를 엽니다. `.env`를 수정하면 서버를 재시작합니다.

## 화면별 사용법

1. **회사 정보:** `가상 정보로 채우기`를 누르고 필요한 값을 수정한 뒤 저장합니다. 서명은 선택 사항입니다. 해커톤 체험에는 합성 정보와 가상 서명을 사용합니다.
2. **오늘의 지원사업:** `실제 공고`로 기업마당 자료를, `체험용 공고`로 가상 자료를 봅니다. `새 공고 확인`으로 다시 조회합니다. 검색어로 원하는 공고를 찾습니다.
3. **신청 준비:** 공고 카드에서 `신청 준비`를 누르고 질문에 답합니다. 구체적인 사실을 입력하세요. PDF에서 의미 없는 답변이나 임의 작성 요청은 보완 필요로 표시됩니다.
4. **PDF 다운로드:** 기본 질문 3개에 답하고 검토 확인란을 선택합니다. 원하는 경우 등록한 서명 삽입도 선택한 뒤 PDF를 내려받습니다.
5. **공식 제출 경로:** 신청 링크가 있으면 접수 사이트로, 없으면 공고 원문으로 이동합니다. PDF 안의 링크도 클릭할 수 있습니다.
6. **준비한 서류:** 이번 실행 중 다운로드한 준비서 목록을 봅니다. 새로고침하면 목록은 초기화됩니다. 실제 파일은 브라우저 다운로드 폴더에 있습니다.

## LLM을 연결하려면

`.env`에 제공자의 전체 API 요청 주소, 키, 모델명을 설정합니다.

- `LLM_API_URL`: Chat Completions 요청을 받는 전체 주소
- `LLM_API_KEY`: 해당 제공자의 인증키
- `LLM_MODEL`: 제공자가 지원하는 모델명

세 값이 모두 있으면 대화 요청을 해당 제공자에게 전달합니다. 회사 기본정보와 대화 내용은 제공자에게 전송되며, 서명 이미지는 제외됩니다. 실제 모델과 정상 대화가 되는지는 키를 설정한 뒤 확인해야 합니다. 현재 PDF는 사용자 답변을 정리한 준비서이며, LLM이 공식 양식을 완성하는 기능은 아닙니다.

## PDF 개선 및 조사 결과

초기 버전의 단순 텍스트 나열을 브랜드 헤더, 회사 정보표, 신청 내용 카드, 공식 자료와 제출 경로, 대표자 확인란으로 바꿨습니다. 서명 영역이 단독 페이지로 밀리는 문제를 개선했습니다.

선택한 박람회의 공식 자료에는 참가신청서·사업자등록증·해당 시 기타 서류가 안내되어 있습니다. 다운로드한 모집자료는 안내문이며 입력 가능한 공식 신청서가 아닙니다. 온라인 신청폼 전체 항목 및 자유양식 PDF 대체 가능 여부는 확인되지 않았습니다.

## 확인한 내용

- 실제 기업마당 API에서 인력 공고 100건 수신
- 회사 정보 저장·복원 및 교차 출처 요청 차단
- 체험 대화와 PDF 다운로드
- 한글·페이지 분할·클릭 가능한 링크 및 PDF 렌더링 확인
- 보완이 필요한 답변 표시 테스트
- TypeScript 검사, 자동 테스트, UI 빌드 통과

다시 확인할 때 앱 폴더에서 실행합니다.

```bash
npm run typecheck
npm test
npm run build
```

`node tests/smoke.mjs`는 localhost:3001 서버를 켠 상태에서 실행하며, 프로필을 잠시 테스트 값으로 바꿨다가 복원하고 `/tmp/ieum-sample.pdf`를 생성합니다. 위 명령은 macOS 로컬 환경 기준입니다. 현재 앱 API는 개발 서버에 붙어 있으므로 운영 배포용 서버는 아직 지원하지 않습니다.
