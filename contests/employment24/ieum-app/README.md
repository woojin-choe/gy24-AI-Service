# 이음 — 고용지원 신청 준비 앱

회사 정보를 기억하고, 기업마당 공고와 대화 내용을 한글 PDF 신청 준비서로 정리합니다. GitHub Pages에 화면을 배포하고 Supabase에서 인증·저장·서버 기능을 제공합니다.

**[GitHub Pages + Supabase 배포 및 실행 안내](docs/github-pages-supabase.md)**

아래 내용은 이전 로컬 프로토타입(`npm run dev:local`, `NEXT_PUBLIC_LOCAL_API=true`)의 동작과 제약을 설명합니다.

[전체 구현 현황 및 팀원 사용법](docs/progress-and-usage.md) · [신청 양식 조사 기록](docs/application-forms.md)

## 실행

Node.js 22.13 이상에서:

```bash
npm ci
cp .env.example .env
# .env에 NEXT_PUBLIC_LOCAL_API=true 설정
npm run dev:local
```

http://localhost:3001 에서 접속합니다. `.env` 변경 시 서버를 다시 실행합니다. 3001 포트를 사용 중이면 기존 앱을 종료하거나 `npm run dev -- --port 3002`로 다른 포트를 지정합니다.

## 사용 흐름

1. 비회원도 메인 화면에서 공고를 조회·검색할 수 있습니다. 오른쪽 상단의 로그인/회원가입 버튼으로 계정 팝업을 엽니다. 회사 정보·신청 준비·준비한 서류는 로그인 후 이용합니다. 이메일·이름·10자 이상의 비밀번호로 회원가입하거나 로그인합니다.
2. 회사 정보를 직접 입력하고 저장합니다.
3. 실제 공고 또는 명시적으로 구분된 체험용 공고를 선택합니다.
4. 활동·목표, 참여 인원·일정, 증빙자료 준비 상황을 입력합니다.
5. 내용을 확인하고 선택적으로 서명 삽입을 승인합니다.
6. 한글 신청 준비서 PDF를 다운로드하고 공고 원문/접수 링크를 엽니다.

## 연동

- 기업마당 공식 지원사업정보 API: https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi
- `searchLclasId=03`으로 인력 분야 첫 100건을 조회합니다. 모든 공고를 수집하는 운영 서비스는 아닙니다.
- API의 공고 ID, 제목, 개요, 신청 기간, 첨부파일 링크, 신청 링크 등을 정규화합니다. 없는 링크는 만들지 않고 공고 원문을 제공합니다.
- 화면이 열려 있는 동안 선택적으로 5분마다 조회하여 새로운 ID에 대한 화면 알림을 표시합니다. 서버 상시 작업·이메일·푸시 알림은 구현 범위 밖입니다.
- 등록한 소재지와 공고 태그를 비교해 관련성 단서를 표시하고 소재지 일치 공고를 위에 표시합니다. 회사별 자격 자동 판정은 하지 않습니다. 검색 및 원문 검토 후 공고를 직접 선택합니다.

### 선택적 LLM 연결

`.env`에서 `LLM_API_URL`, `LLM_API_KEY`, `LLM_MODEL`을 설정하면 OpenAI 호환 Chat Completions 요청 형식으로 대화를 연결합니다. 미설정 시 실제 LLM이 아닌 고정 3단계 체험 대화를 사용합니다. 서명은 LLM에 보내지 않으며, 회사 정보와 대화 내용은 설정한 제공자에게 전달됩니다.

## PDF 범위

한글 텍스트와 클릭 가능한 공고/신청 링크, 선택한 서명을 포함한 **신청 준비서**입니다. 기관 공식 신청 양식 자동 작성·제출은 아닙니다. 실제 신청서 자동 채움은 대상 사업 하나를 정한 뒤 해당 양식의 항목 매핑을 추가해야 합니다.

macOS의 Arial Unicode TTF를 기본 사용합니다. 다른 환경에서는 `.env`의 `PDF_FONT_PATH`에 한글을 지원하는 TTF 경로를 설정하세요. 시스템 폰트는 저장소에 복사하지 않습니다.

## 저장과 보안

- 이메일·비밀번호 회원가입, 선택적 자동 로그인, 로그아웃을 지원합니다. 비밀번호는 사용자별 salt와 scrypt 해시로 저장하며 원문은 저장하지 않습니다.
- 계정과 해시 처리한 세션은 Git에서 제외된 `.local/accounts.json`, 회사 정보와 서명은 `.local/users/<계정 ID>/profile.json`에 저장합니다. 자동 로그인 미선택 시 브라우저 세션 쿠키(서버 만료 12시간), 선택 시 30일 유지 쿠키를 사용합니다. 다음 방문 시 유효한 쿠키로 로그인 상태를 복원하며 로그아웃하면 폐기합니다. 인증 쿠키는 HttpOnly·SameSite=Lax이며 HTTPS에서는 Secure를 사용합니다.
- 회사 정보 조회·수정·삭제와 대화·PDF 생성 API는 로그인이 필요합니다. 기존 공용 `.local/profile.json`은 계정으로 자동 이전하지 않습니다.
- 계정은 이 서버에 저장됩니다. 이메일 인증·비밀번호 재설정·소셜 로그인은 제공하지 않습니다.
- 해커톤 시연에는 합성 정보와 가상 서명을 사용합니다.
- 팀 공용 기업마당 API 키는 `.env.example`에 포함되어 있습니다. 실행 시 `.env`로 복사하며 브라우저 응답에는 포함하지 않습니다. LLM 키와 개인 설정은 `.env`에만 저장합니다.
- 삭제 버튼으로 저장된 프로필을 비울 수 있습니다. 내려받은 PDF는 직접 관리합니다.
- 여러 사용자가 접속하는 공개 서비스로 배포하려면 HTTPS·이메일 인증·비밀번호 재설정·운영용 데이터베이스·보관 정책·지속 작업·키 관리 등을 구현해야 합니다.
- 로컬 API는 `dev:local` 전용입니다. 운영 빌드는 정적 `out/`을 생성하며 서버 기능은 Supabase Edge Function에서 제공합니다.
