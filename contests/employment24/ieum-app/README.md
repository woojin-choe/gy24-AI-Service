# 이음 — 로컬 고용지원 신청 준비 앱

회사 정보를 기억하고, 기업마당의 인력 분야 공고를 조회한 뒤 필요한 정보를 대화로 받아 한글 PDF 신청 준비서를 만드는 로컬 프로토타입입니다.

[전체 구현 현황 및 팀원 사용법](docs/progress-and-usage.md) · [신청 양식 조사 기록](docs/application-forms.md)

## 실행

Node.js 22.13 이상에서:

```bash
npm ci
cp .env.example .env
# 팀 공용 기업마당 키가 포함된 설정 복사 완료
npm run dev
```

http://localhost:3001 에서 접속합니다. `.env` 변경 시 서버를 다시 실행합니다. 3001 포트를 사용 중이면 기존 앱을 종료하거나 `npm run dev -- --port 3002`로 다른 포트를 지정합니다.

## 사용 흐름

1. 회사 정보에서 `가상 정보로 채우기`를 선택하고 저장합니다.
2. 실제 공고 또는 명시적으로 구분된 체험용 공고를 선택합니다.
3. 활동·목표, 참여 인원·일정, 증빙자료 준비 상황을 입력합니다.
4. 내용을 확인하고 선택적으로 서명 삽입을 승인합니다.
5. 한글 신청 준비서 PDF를 다운로드하고 공고 원문/접수 링크를 엽니다.

## 연동

- 기업마당 공식 지원사업정보 API: https://www.bizinfo.go.kr/apiDetail.do?id=bizinfoApi
- `searchLclasId=03`으로 인력 분야 첫 100건을 조회합니다. 모든 공고를 수집하는 운영 서비스는 아닙니다.
- API의 공고 ID, 제목, 개요, 신청 기간, 첨부파일 링크, 신청 링크 등을 정규화합니다. 없는 링크는 만들지 않고 공고 원문을 제공합니다.
- 화면이 열려 있는 동안 선택적으로 5분마다 조회하여 새로운 ID에 대한 화면 알림을 표시합니다. 서버 상시 작업·이메일·푸시 알림은 구현 범위 밖입니다.
- 등록한 소재지와 공고 태그를 비교해 관련성 단서를 표시하고 소재지 일치 공고를 위에 표시합니다. 회사별 자격 자동 판정은 하지 않습니다. 검색 및 원문 검토 후 공고를 직접 선택합니다.

### 선택적 LLM 연결

`.env`에서 `LLM_API_URL`, `LLM_API_KEY`, `LLM_MODEL`을 설정하면 OpenAI 호환 Chat Completions 요청 형식으로 대화를 연결합니다. 미설정 시 실제 LLM이 아닌 고정 3단계 체험 대화를 사용합니다. 서명은 LLM에 보내지 않으며, 회사 정보와 대화 내용은 설정한 제공자에게 전달됩니다.

## PDF 범위

한글 텍스트와 클릭 가능한 공고/신청 링크, 선택한 서명을 포함한 **신청 준비서**입니다. 기관 공식 신청 양식 자동 작성·제출은 아닙니다. 실제 신청서 자동 채움은 대상 사업 하나를 정한 뒤 해당 양식의 항목 매핑을 추가해야 합니다.

macOS의 Arial Unicode TTF를 기본 사용합니다. 다른 환경에서는 `.env`의 `PDF_FONT_PATH`에 한글을 지원하는 TTF 경로를 설정하세요. 시스템 폰트는 저장소에 복사하지 않습니다.

## 저장과 보안

- 회사 정보와 서명은 Git에서 제외된 `.local/profile.json`에 저장합니다. 단일 사용자·로컬 실행용이며 인증은 없습니다.
- 해커톤 시연에는 합성 정보와 가상 서명을 사용합니다.
- 팀 공용 기업마당 API 키는 `.env.example`에 포함되어 있습니다. 실행 시 `.env`로 복사하며 브라우저 응답에는 포함하지 않습니다. LLM 키와 개인 설정은 `.env`에만 저장합니다.
- 삭제 버튼으로 저장된 프로필을 비울 수 있습니다. 내려받은 PDF는 직접 관리합니다.
- 여러 사용자가 접속하는 공개 서비스로 배포하려면 인증·권한·보관 정책·지속 작업·키 관리 등을 구현해야 합니다.
- 로컬 API는 Vite 개발 서버 미들웨어로 제공합니다. `npm run build`는 UI 빌드 검증이며 `npm start`의 운영 API 제공은 지원하지 않습니다.
