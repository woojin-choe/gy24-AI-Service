# [아이디어 후보 A] 2026 고용24 해커톤 — "컴백브릿지(Comeback Bridge)"

**한 줄 비전**
육아·가족돌봄으로 휴직했던 근로자가 복귀할 때, AI가 휴직 기간 동안 벌어진 역량 공백을 진단하고 맞춤 복귀 로드맵을 설계해주는 동시에, 사업주에게는 받을 수 있는 지원금을 자동 매칭해주는 복귀지원 에이전트

---

## 1. 문제정의 및 근거
- **남성 육아휴직급여 수급자 6만7,200명, 전체의 36.5%, 전년대비 60.7%↑** (여성 증가율 29.1%를 크게 앞지름) — [네이트뉴스](https://m.news.nate.com/view/20260224n31982), [한국경제](https://www.hankyung.com/article/2025121799281), [고용노동부 e뉴스](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=18514)
- 2015년 남성 육아휴직자 4,872명(5.6%) → 10년 새 **13.8배 증가** — 맞돌봄 문화 확산 추세가 통계로 명확히 입증됨
- 2026년 상반기 육아휴직급여 수급자 4만320명 중 남성 비중 38.8% — [네이트뉴스](https://m.news.nate.com/view/20260712n06606)
- 가족돌봄휴직은 연 최대 90일, 분할사용 가능, 자녀 외 가족 돌봄 전반 포괄 — [easylaw.go.kr](https://easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1380&ccfNo=1&cciNo=3&cnpClsNo=1)
- 사업주 대상 지원금(육아휴직지원금 월 30만~100만원, 대체인력지원금 월 최대 140만원, 업무분담지원금 월 최대 60만원)은 전부 **정액 지급 구조일 뿐** — [easylaw.go.kr 고용안정장려금](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?popMenu=ov&csmSeq=1380&ccfNo=2&cciNo=3&cnpClsNo=1)

## 2. 기존 서비스 대비 차별점
- 지원금 제도는 촘촘히 있지만, **복귀 당사자의 역량공백 진단이나 개인화된 복귀 로드맵을 제공하는 AI 서비스는 조사 범위 내 미발견**
- "경력단절여성" 전용이 아니라 **성별 무관, 고용보험 기반의 가족돌봄휴직 전체**로 설계 → 여성가족부(새일센터) 소관 리스크를 피하고 고용노동부 본연 영역(일·가정양립)에 안착
- 중장년내일센터·나만의AI고용센터(국민취업지원제도 참여자 스코어링)와도 대상군이 겹치지 않음(재직자의 휴직 복귀이지 구직자가 아님)

## 3. 핵심 구조
1. 고용24 데이터(이력서, 고용보험 가입이력, 육아휴직급여 신청이력) 연동
2. AI가 휴직기간·이전 직무·업계 변화(구인배율·기술 트렌드)를 분석해 **"역량 공백 리포트"** 자동 생성 (예: "휴직 중 업계에서 A 툴/자격이 신규 표준이 됨")
3. 개인별 맞춤 **복귀 로드맵** 설계 — 필요 재교육 과정 추천(HRD-Net 연계), 단계적 업무 복귀 플랜
4. 사업주 측에는 고용안정장려금·대체인력지원금·업무분담지원금 중 해당 사업장이 받을 수 있는 조합을 자동 매칭 (부가 기능, "이음"의 서류자동화 로직 재사용 가능)

## 4. 사용 데이터
- 고용24 API(이력서·고용보험 가입이력·육아휴직급여 신청이력)
- EIS(고용행정통계): 산업별 직종 변화·구인배율 통계
- data.go.kr: 모성보호 육아휴직 통계
- ELDS: 직업훈련 이수 이력
- 역량공백 진단 로직은 비공개 개인 데이터이므로 **합성데이터로 구현** (요강 허용 조항)

## 5. 심사기준 대응 (100점)
| 기준 | 평가 |
|---|---|
| 대상 적합성(25) | 강함 — 급성장 중인 모집단(남성 육아휴직 60.7%↑), 저출생 대응 국정과제와 직결 |
| AI·데이터 타당성(25) | 중상 — 공공데이터로 역량공백 진단 로직 설계 가능하나, 2주 MVP로는 룰베이스+간단 NLP 수준이 현실적 한계 |
| 실행계획(20) | 양호 — 데이터 구조 단순, 2주 내 데모 가능 |
| 독창성·차별성(20) | 강함 — 유사 AI 서비스 확인된 바 없음 |
| 기대효과(10) | 강함 — 저출생 대응이라는 명확한 정책 부합성 |

## 6. 리스크 관리
- "돌봄" 프레이밍이 여성가족부 사업(새일센터 등)과 혼동될 수 있음 → 발표 시 **"고용보험 기반·전성별·전가족돌봄"** 임을 명시적으로 강조
- 역량공백 진단의 "정교함"을 과도하게 어필하지 말 것 — 2주 MVP 한계를 솔직히 인정하고 룰베이스 버전을 "확장 가능한 프레임워크"로 포지셔닝
