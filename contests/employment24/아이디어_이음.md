# [아이디어 최종안] 2026 고용24 해커톤 — "이음(Ieum)"

**한 줄 비전**
대한민국 국민·사업주가 "몰라서" 또는 "절차가 복잡해서" 놓치는 모든 고용 혜택을, AI가 생애주기 내내 상시 감지해서 신청서류까지 완성해 버튼 하나로 제출하게 만드는 고용 혜택 자동집행 에이전트

---

## 1. 문제정의 및 근거
- 중소기업 지원제도 미활용 이유 46.6%가 "제도 내용/방법을 몰라서" (중소기업중앙회 502개사 실태조사)
- 노무사 대행업체가 지원금액의 10~30%를 수수료로 받는 시장이 이미 존재 → "서류작성 자체가 진입장벽"이라는 확실한 방증
- 중소기업 이직률 5.4%(대기업 3.6%보다 높음), 300인 미만 사업장 8만개+ 일자리 미충원
- 특고 노동자는 "합산특례"처럼 정부가 데이터는 갖고 있어도 신청은 본인이 해야 하는 절차가 있음

## 2. 기존 서비스 전수 조사 결과 (전부 "제시/추천"에서 멈춤)
- 고용24 AI매칭(2020~) — 이력서-공고 매칭만
- 잡코리아 원픽, 사람인 스마트리크루터, 원티드 — 전부 채용 매칭
- 기업마당(bizinfo.go.kr) — 규칙기반 필터+알림, AI 개인화 아님
- govmatch.kr 등 민간 AI 매칭 서비스 — R&D·정책자금 중심, 서류작성 기능 없음
- **고용24 '펌케어 AI'**(2026 하반기 정부 로드맵) — 채용 시 지원금 "제시"까지만
- **'나만의 AI 고용센터'**(대전 시범, 국민취업지원제도 참여자 AI 스코어링) — 구직자 스코어링까지만
- 근로복지공단 — 플랫폼 소득은 법적으로 이미 자동 합산·관리 중이지만, 그걸로 뭘 신청해야 하는지는 안 알려줌

→ **정부·민간 모두 "인지시키는 것"까지만 하고, "신청 실행(서류 완성·제출)"은 항상 사람이 직접 해야 하는 구간으로 비어있음. 여기가 진짜 빈틈.**

## 3. 핵심 구조
1. 사업자등록번호/개인 인증으로 고용24 데이터 연동 (근로자 변동·고용보험 이력·훈련이력 등, 비공개 데이터는 요강상 허용된 합성데이터로 구현)
2. AI가 생애주기 이벤트 상시 감지 (신규채용, 60세 계속고용 갱신, 육아휴직 대체인력, 이직, 훈련 이수 등)
3. 해당 이벤트에 걸리는 모든 제도(장려금·지원금·수당) 자동판별 + 충족률(%) 표시
4. 생성형 AI가 실제 신청서식에 정보를 자동으로 채워 신청서류 완성 → 제출 직전까지 원스톱
5. MVP 데모는 **사업주 시나리오 1개 + 개인 근로자 시나리오 1개**만 구현 → "같은 엔진으로 모든 대상 확장 가능"함을 증명

## 4. 심사기준 대응 (100점 만점)
- 아이디어 정의·대상 적합성(25): 특정 소수집단이 아니라 전 국민·전 사업주가 잠재 대상 — 체감 폭 최대
- AI·데이터 활용 타당성(25): 고용24 API + EIS/ELDS + 생성형 AI 문서자동화, 전부 근거 검증됨
- 실행계획 적정성(20): 2주 내 "이벤트감지→자격판별→서류자동생성" 시나리오 2개로 스코프 한정
- 독창성·차별성(20): 정부의 개별 파일럿들(펌케어AI, 나만의 AI 고용센터)을 통합하는 상위 "실행 레이어" — 아무도 안 가진 개념
- 기대효과(10): "몰라서 놓치는 혜택 46.6%"라는 구조적 문제를 없애는 국가 인프라급 스토리

## 5. 리스크 관리
- 기획서에 "펌케어AI/나만의 AI 고용센터는 인지·매칭까지, 이음은 그 다음 단계인 신청 실행까지"라는 차별점을 앞부분에서 명확히 서술할 것
- MVP는 반드시 실제 작동하는 2개 시나리오로 좁혀서 "실행계획 적정성"에서 감점 안 받게 할 것
